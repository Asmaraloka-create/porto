# Foto projek sendiri

Mau mengganti screenshot otomatis dengan foto sendiri?

1. Taruh file di folder ini, contoh:
   - public/projects/kurumi.jpg
   - public/projects/game.jpg
2. Edit src/data/content.js, ganti field image:
   - image: '/projects/kurumi.jpg'
3. Rebuild / refresh. Ukuran ideal: 800x600 atau 1200x800 (JPG/WebP).
